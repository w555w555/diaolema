# 首页 UI 排版 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把现有天气、建议、识鱼、渔场、渔获接到消费级首页排版：钓鱼指数、功能格、动态流；地图改到底部「钓点」。

**Architecture:** 手机列壳 + 底栏五个入口。首页只编排现有能力，不新做约钓/导钓/接待。`buildFishingIndex` 纯函数，与 `buildAdvice` 同套气象输入。高德地图常驻 DOM，切 Tab 时用 visibility 隐藏以免卸载重载。

**Tech Stack:** React 19 + 现有 CSS（不引入 Tailwind）+ Vitest
