# FR-7 AI 识别鱼种

> 状态：Draft → Ready for implementation  
> 日期：2026-08-17  
> 对应：`docs/spec/PRD.md` FR-7、`docs/spec/SDD.md` §10

## 1. 一句话

钓友拍一张渔获照片，应用识别出鱼种（中文名），置信度不够就明说不确定，识别结果可一键填进「报渔获」并钉到高德标点。

## 2. 用户故事

1. 作为上海钓友，我把刚钓上来的鱼拍一张，想马上知道是鲫还是鲤、是鲈还是翘嘴。
2. 作为上报渔获的人，我不想手打鱼名，识别后直接用这个名字钉到地图上：`我 刚刚 钓到了鲈鱼`。
3. 作为使用者，我希望前三名候选可点选，避免模型认错却无法改。

## 3. 功能需求

### FR-7.1 取图

- 入口：底栏中间金色按钮，按钮上写 **AI 识鱼**，下方不另标「识鱼」。打开后为识鱼页，含拍照与相册；同页可手动报渔获。首页不放识鱼卡。已配置密钥时不展示豆包品牌、不放「打开豆包」链接；拍照后弹出扫描窗，成功则打钩再出结果。
- 支持：手机后置相机现场拍照（系统相机 `capture=environment`；HTTPS/localhost 下可实时取景快门）；相册选图。电脑端相册上传，有摄像头时可拍照。
- 仅接受图片（jpeg / png / webp / heic 若浏览器可解码）。单张不超过 8 MB（压缩前）。
- 上传前在浏览器内压缩：最长边 ≤ 1280 px，JPEG 质量约 0.8，再送给识别服务。原图不默认上传到公网图床。识图请求关闭深度思考，但必须用高清图和外形核对提示，不得用 low-detail 缩略图。

### FR-7.2 识别

- 输出必须是结构化结果，禁止只吐一段散文：

  | 字段 | 说明 |
  |------|------|
  | `species` | 中文标准名，必须来自上海对象鱼词表，或 `不确定` |
  | `confidence` | 0–1 |
  | `alternatives` | 最多 3 个候选（名 + 置信度） |
  | `cues` | 1–3 条外形依据（口位、体色、鳍、斑纹），给钓友核对 |
  | `inCatalog` | 是否落在词表内 |

- **词表（上海淡水 / 河口优先）**：鲫鱼、鲤鱼、草鱼、青鱼、鳊鱼、鲈鱼、翘嘴、白条、黑鱼、黄颡鱼、罗非鱼、鳜鱼、黄鱼、鲻鱼、鲶鱼、塘鲺、鳡鱼、红鳍鲌、鲮鱼、鳊（与鳊鱼合并显示为鳊鱼）。
- 模型若返回英文或别名（如 `largemouth bass`、花鲈、七星鲈、乌鳢、黄辣丁），必须经 `normalizeFishName` 映射到词表。映射不到 → `不确定`，不得编造词表外的「新种」当确定结果。
- 主名是 `不确定`、但第一候选已在词表内时，采用该候选（置信度上限 0.62），避免把「其实认出来了」整段丢掉。
- `confidence < 0.45` 或模型拒绝 → 展示「认不太准」，列出候选，不自动写入报渔获。
- 不是鱼、空图、模糊、手挡住主体、且没有任何词表候选 → `species = 不确定`，说明原因。
- 提示词须区分翘嘴与白条：口裂向上、下颌长于上颌判翘嘴，不因鱼小就判白条。

### FR-7.3 与现有功能衔接

- 用户点「用这个鱼名上报」：把 `species` 填入报渔获的鱼种，作者默认「我」，时间=现在，坐标=当前定位或地图选点；若有当场照片则写入本机 `imageUrl`（压缩 JPEG），不把 data URL 发到飞书。
- 不自动发到小红书/抖音。
- 识鱼失败不影响天气、地图、日报。

### FR-7.4 明确不做

- 不做鱼类疾病诊断、是否可食用、是否国家保护动物的法律鉴定（可在文案提示：保护鱼类请放流，以官方名录为准）。
- 不把照片默认存云端相册；本机可选缓存最近一张缩略图（session 内）。
- 不调用需要破解的第三方「识鱼 App」私有接口。

## 4. 非功能

- 识别超时 120s，可取消。请求必须带 `thinking: { type: "disabled" }`，禁止默认深度思考；提示只要短 JSON。超时界面提示换更小的图再试。
- 识别服务：**豆包（火山方舟 ARK）**。不自动登录 https://www.doubao.com 网页填表。本机把压缩图片发到 `https://ark.cn-beijing.volces.com/api/v3/chat/completions`（模型 `doubao-seed-2-1-turbo-260628`），解析回复后回填识鱼界面。
- 需要火山方舟 API Key（`ark-…`），写入 `.env` 的 `FISH_ID_API_KEY`。未配置时可手动词表点选。
- 照片二进制只在当次请求中使用，服务端不写磁盘（除非后续单独做「本机图库」并写进 Spec）。

## 5. 验收标准

1. 上传一张清晰鲫鱼/鲤鱼/鲈鱼类照片，返回词表内中文名 + 置信度 + 依据。
2. 模糊图或鞋子照片 → `不确定`，不假装认出鱼。
3. 「用这个鱼名上报」后，高德标点附文为 `我 刚刚 钓到了{鱼名}`。
4. 未配 Key 时有明确提示，且可手动选词表鱼种。
5. `normalizeFishName` 单测覆盖别名（乌鳢→黑鱼，黄辣丁→黄颡鱼，花鲈→鲈鱼）。

## 6. 成功标准

`npm test` 含词表归一化；配好 Key 后在 `启动钓了嘛.bat` 或 `npm run dev` 里能完成「拍照 → 认出 → 钉到地图」演示。
