# 钓了嘛 Product Spec（PRD）

> 状态：Approved for MVP  
> 日期：2026-08-17  
> 范围：上海地区钓鱼助手 Web 应用

## 1. 一句话

给上海钓友一张高德地图：看实时天气（含气压、湿度），据此推荐水层 / 鱼饵 / 钓法；把渔获情报钉在地图上；拍照让 AI 认出鱼种后再上报。

## 2. 目标用户

业余与半专业淡水 / 河口钓友，主要活动范围：上海及周边（滴水湖、淀山湖、崇明、滨江、公园湖等）。

## 3. 功能需求

### FR-1 实时天气

- 默认定位上海人民广场。手机上进入应用（开屏结束后）请求浏览器定位，用于天气、钓点附近与识鱼/报渔获坐标；打开底栏「+」或「钓点」会再定位一次。定位失败（未授权 / 非 HTTPS / 超时 / 不支持）仍用人民广场，并说明原因。允许在地图选点覆盖当前坐标。
- 展示：天气现象、气温、体感、相对湿度、海平面气压、3 小时气压趋势、风速风向、降水。
- 数据源：Open-Meteo（无需密钥，CORS 可用）。后续可替换为和风 / 高德天气，接口保持 `WeatherSnapshot`。

### FR-2 作钓建议

根据 FR-1 的气象快照 + 当前小时 + 月份 + **用户选的目标鱼** + **台钓/路亚**，给出：

| 输出 | 说明 |
|------|------|
| 推荐水层 | 上层 / 中上层 / 中下层 / 底层 |
| 味型与饵形 | 台钓：味型+饵形；路亚：按对象鱼给出拟饵种类、克数/尺寸、颜色、操法 |
| 标点 | 水草区、进水口缓流、凸岸、草洞等，随对象鱼与气象变化 |
| 窗口 | 早晚优先 / 避开正午 / 按气压择时 |
| 理由 | 用气压趋势、气温、风力、对象鱼解释，避免空话 |

建议引擎必须是确定性规则（可单测），不在运行时调用大模型或再去网上搜。规则编译自公开垂钓经验（渔钓者味型与选点、龙国钓鱼频道饵料变更；路亚：渔夫者/钓鱼007 翘嘴亮片克数、渔钓者雷蛙操法、酷钓鱼铅头钩克数表、酷米网瓜子亮片），不是溶氧/水温实测，也不是线上实时大数据模型。

### FR-3 上海渔获情报地图

- 环境变量：`VITE_AMAP_KEY` / `AMAP_KEY`。无 Key、SDK 超时或失败时降级为国内可显示的高德栅格底图，并提示配置；不得一直停在「正在加载地图」。
- 每个高德标点**下方常显**附文，格式固定为：

  `某某某 多少时间之前 钓到了什么鱼`

  例：`沪上老张 3小时前 钓到了鲈鱼`

- 附文须带来源标签：小红书 / 抖音 / 微博 / 公开渔讯 / 钓友上报。
- **鱼情来源（必须覆盖）**：小红书、抖音，以及任何可合法获得的上海鱼情（公开网页、渔讯、用户粘贴的分享口令/文案）。
- 入库方式：① 粘贴小红书/抖音/微博/微信公众号分享文案或公开链接，解析谁、何时、何鱼、何地并钉到对应钓点；② 公开渔讯整理样本；③ 钓友本机上报。渔获库是飞书多维表格，由本机 `lark-cli` 读写，不再用 SQLite。
- **鱼情日报（FR-5）**：每日自动公开信息发现。已启用平台：小红书 `xiaohongshu.com`、抖音 `douyin.com`、微信公众号 `mp.weixin.qq.com`、B站 `bilibili.com`、贴吧 `tieba.baidu.com`、知乎 `zhihu.com`。只允许：① 用搜索引擎公开结果，按城市、平台、关键词生成查询；② 保存标题、摘要、链接；③ 对公开可访问网页尝试读正文；④ 登录墙平台仅保留标题、摘要、链接；⑤ AI 摘要、入库、生成 `fish_scout_data/reports/` 日报。不登录、不绕验证码、不模拟 App、不抓私密内容。公开发现使用项目 skill：`baidu-search`（千帆网页搜索，按平台 `sites` 过滤）、`multi-search-engine`（Bing 中国 / 百度网页 / 搜狗微信 / DuckDuckGo）、`defuddle`（仅非登录墙公开页抽正文）。每条命中必须属于**该条查询自己的** `site`（含别名），不能把别的平台结果混进当前查询。
- **不做**：登录用户账号去爬小红书/抖音/微信公众号全站、绕过验证码或接口签名。平台无开放检索 API 时，用分享入库 + 公开网页 + 公开搜索摘要，不用黑产爬虫。
- 用户可在地图上报自己的渔获，写入飞书多维表；浏览器 localStorage 只作离线缓存。
- 高德 SDK 真正加载成功后才显示「高德已开启」。
- **渔场目录（FR-6）**：地图与列表展示上海地区收费渔场 / 路亚营地 / 钓鱼营地。数据来自：① 大众点评公开商户页（店名、人均、状态）；② 钓鱼之家公开钓场目录（收费、区县、路名）；③ 路亚塘等公开页（仅收录有区县或路名的营地）。**钓点地图只显示营地钉，不常显长附文、不叠渔获气泡**，避免过密。每次从底栏进入「钓点」先定位，初始视野对准当前位置（约 14 级）；定位失败则仍用人民广场。拉远时营地收成小头像钉，靠近后再展开铭牌，避免全市大铭牌叠在一起。钓点页提供一份整合列表：默认按渔见均分从高到低排（同分看条数，无分排最后，名次用第 N），并可用搜索过滤（店名 / 区县 / 路名 / 类型）。**每条排行显示反馈条数**（N 条反馈 / 暂无反馈）。点店名或条目进入本机钓场详情，不跳转钓鱼之家 / 大众点评 / 路亚塘网页；目录来源只作文案。从排行进入详情后关闭，回到排行。地图上只保留一个「钓场」入口，不再分营地列表与排行榜。高德底图用官方浅色标准样式（`amap://styles/normal`），关闭默认兴趣点，画布未加载时用浅灰而不是深色。每颗钓场用**分类铭牌**：头像、店名、五星、类型、区县路名与收费。有客户反馈图则用该图作头像，**没有照片时用渔见 Logo**。白底圆角，下沿三角对准坐标。评分最多五星，可用半星，**界面不展示数字分**。内部仍按客户反馈星级均分（可单测）。无反馈为五颗空星并标「新」。不用圆圈也不用水滴。示例反馈可用公开图库照片（本机 `public/spot-photos/`）与虚拟星级，须标明示例。钓友可在详情里写 1–5 星反馈（本机 localStorage，不写飞书）。不把点评星级直接当渔见分。不登录点评/钓鱼人 APP。不含免费野点与斤塘。坐标按公开区县与路名估算。暂停营业或已关门的仍列出。

### FR-7 AI 识别鱼种

详细规格见 [`docs/spec/FR-7-fish-id.md`](FR-7-fish-id.md)。

- 钓友上传或拍摄渔获照片，识别为上海对象鱼词表中的中文名，并给出置信度、最多 3 个候选、1–3 条外形依据。
- 置信度低或不是鱼时必须返回「不确定」，不得编造。
- 识别结果可一键填入报渔获并钉到高德，附文仍为 `某某某 多少时间之前 钓到了什么鱼`。
- 无豆包 API Key 时可手动点选词表，不算 AI 识别。
- 走火山方舟豆包识图接口，不自动登录豆包网页填表；照片不默认存公网。
- 手机优先：底栏「+」识鱼与同页报渔获都提供**拍照**（`capture=environment` 系统相机；安全上下文下可用实时取景）和相册。上报可将压缩图作为本机分享封面，不把 data URL 写入飞书。

### FR-8 策略首页（深色金青绿）

- 默认打开**策略**首页，不是铺满地图。视觉按深底、金强调、青绿辅色。产品对外名 **渔见**。首页只保留：**品牌、天气条、今日最佳方案、今日渔获**。品牌行：`public/logo.svg` + 「渔见」（Logo 同款字族与渐变字色）+ 辅文 FISHING INSIGHT。进入应用先弹出开屏：金青绿光晕、水纹、Logo 淡入，点按或约 2.4 秒后进入策略页。点鱼名更换目标鱼；旁侧「介绍」打开该鱼说明。常用工具不占首页（钓点/渔圈走底栏，渔获记录从「我的」进入，点天气条打开天气详情）。AI 识鱼不放首页卡，走底栏中间金色「AI 识鱼」。
- 底部五个入口：**策略**、**钓点**（高德/降级地图）、中间金色按钮写 **AI 识鱼**（打开识鱼页，可拍照后上报；同页可手动报渔获；不用 + 号，按钮下方不另标「识鱼」）、**渔圈**（装备商城 / 赛事 / 技巧 / 评测 / 社区群聊）、**我的**（个人中心）。策略、钓点之后的下一主页面是渔圈。
- 天气条展示气温、出钓适宜度、风向风力、湿度与气压（一行辅文），以及窗口期倒计时。点天气条打开完整天气。
- **窗口期倒计时**：晨间窗口 05:00–08:00、黄昏窗口 17:00–20:00，与建议引擎 `prime` 小时一致。窗口内显示「晨间窗口剩余 / 黄昏窗口剩余」，窗外显示「距晨间窗口 / 距黄昏窗口」。每秒刷新。不依赖溶氧/水温。
- 今日最佳方案来自 FR-2：对象鱼、水层、**味形/拟饵**、**标点**。台钓/路亚切换与窗口倒计时不在方案格里重复。切换台钓/路亚或更换目标鱼会立刻重算，不另调模型。点鱼名换鱼；「介绍」打开本机鱼类习性与台钓/路亚技巧（`fishGuide`），不联网、不编造溶氧水温。
- **目标鱼按钓法筛选**：台钓只列饵钓对象（鲫、鲤、草、青、鳊、鲮、黄颡、黄鱼、鲻鱼）；路亚只列掠食对象（鲈、翘嘴、黑鱼、鳜、鳡、红鳍鲌）；白条、罗非、鲶、塘鲺两边都可。切换钓法时，当前鱼若不匹配则改默认（台钓鲫鱼 / 路亚翘嘴）。识鱼上报仍用全词表。规则编译自渔钓者/酷钓鱼/饵料网公开对象鱼文，运行时不联网。
- AI 识鱼入口在底栏中间金色按钮（按钮上写 **AI 识鱼**，下方不重复「识鱼」）。进入后展示拍照/相册与识别结果（鱼名、置信度、外形依据）；无结果时引导去拍照。点按「拍照」优先打开后置相机（系统相机或本机取景），也可从相册选图。**已配置识鱼密钥时**界面不出现「豆包」或「打开豆包」；识别中弹出搞笑钓者把渔见 Logo 从水里钓起：表情轻微用力，旁白「嘿呀」，钓起即成功。首页不放识鱼卡。
- **钓友分享**：天气/方案留在上半屏不随分享被顶走。分享区在方案下方独立滑动（不显示滚动条）。区头为「今日渔获」加条数，右侧「全部 ›」，下沿细金线。**双列卡片**：封面限高约 108px，不必滑完一张图才看到下文。图上鱼种胶囊、示例黑底白字；图下标题一行、钓点名与点赞。点赞与关注作者只存在本机（localStorage），不写飞书、不做粉丝列表/私信。点卡片打开短文详情：顶图叠作者与时间，可关注/点赞，正文去掉「示例短文」声明，「去钓点」为全宽青绿按钮。再切地图。「全部」进「我的」渔获记录。
- **钓鱼指数** 仍由气象规则算出 0–100 与档位（可单测）。不调用大模型，不编造日最高最低气温、溶氧、水温。
- 本机分享流可关注作者、点赞；不做一对一私信、约钓组队、导钓下单。桌面端以圆角手机列居中；地图在「钓点」Tab 常驻，切换时不卸载。首页留白优先于堆叠卡片。

### FR-10 我的（个人中心）

底栏最后一页，按常规 App 个人中心：

- 顶栏：头像（渔见 Logo）、昵称、城市、一句简介。可改昵称与简介，存本机，**不接账号登录**。
- 四列数据：渔获、关注、粉丝、想买。粉丝为示例钓友名单（须标明示例），点开可看列表，**不接私信**。
- 分组列表：渔获记录、想买清单、分享入库、我的粉丝；定位与天气、鱼情日报；关于渔见。
- 从首页「全部」进入时直接打开渔获记录。点渔获可导航到钓点地图。
- 定位、重试天气、分享入库不再堆在首页式卡片里。

### FR-9 渔圈（第三主页面）

策略、钓点之后的主页面。底栏文案 **渔圈**。五个入口：

| 入口 | 行为 |
|------|------|
| 装备商城 | 本机示例商品目录（竿/轮/饵/线）。可加入「想买」。**不接支付、物流、第三方商城登录。** |
| 赛事 | 上海及周边示例赛事列表（时间、地点、项目）。标明示例，不接官方报名接口。 |
| 钓鱼技巧 | 台钓 / 路亚短文，正文写在本机 JSON，运行时不调模型、不联网。 |
| 装备评测 | 示例评测 + 本机 1–5 星写评（localStorage）。界面用五星，不展示数字分。 |
| 钓鱼社区 | 主题群列表。点进群后可看历史消息、发送一条本机消息。**群聊只存在本机，刷新后用户消息仍在；不是公网 IM，不是一对一私信。** |

全部示例内容须能看出是演示。不登录钓鱼人 / 淘宝 / 微信。

### FR-4 明确不做（本迭代）

- 不登录爬取、不绕过小红书/抖音/微信公众号反爬与鉴权。
- 不自动登录小红书 / 抖音 / 微信公众号去全站抓取。
- 地图演示仍以上海为主；鱼情日报覆盖配置里的 `selected_locations`。

## 4. 渔获数据策略（合规）

| 来源 | MVP | 以后 |
|------|-----|------|
| 小红书分享口令 / 公开文案入库 | 做 | 官方开放接口则改直连 |
| 抖音分享口令 / 公开文案入库 | 做 | 官方开放接口则改直连 |
| 微博 / 公开渔讯网页 | 做（可拉取公开 HTML 正文） | 持续收录 |
| 微信公众号分享文案 / 用户粘贴的公开链接 | 做 | 官方开放接口则改直连 |
| 本机 `save_post` + 飞书多维表（`lark-cli`）+ `fish_scout_data/posts/` 归档 | 做 | 与地图标点同步 |
| 用户手动保存的链接 | 做 | 写入 `manual_links` 后参与日报 |
| 公开搜索摘要（标题/链接/摘要，不抓登录墙正文） | 做 | 失败则跳过，不影响日报 |
| 百度千帆网页搜索（`BAIDU_SEARCH_API_KEY` / skill config，可选） | 做 | 无 Key 则跳过，改用公开 SERP |
| 大众点评公开商户（上海渔场店名/人均/状态） | 做 | 有官方开放接口则改直连 |
| 登录爬全站 / 破解接口 / 自动刷站 | 永不做 | 永不做 |

产品文案必须让用户看出哪些是示例、哪些是自己报的。

## 5. 非功能

- 中文 UI；移动端优先（首页卡片 + 底部导航；地图在「钓点」）。手机需定位与相机权限；非 HTTPS 时系统相机选图仍可用，浏览器定位与实时取景不可用。
- 可部署到 **Zeabur**：控制台用 GitHub 仓库，或本机 `npx zeabur@latest deploy`。构建 `vite build`，启动 `npm start` 监听 `PORT`。云端 HTTPS，手机定位与实时取景可用。密钥只配 Zeabur 变量，不提交 `.env`。
- 天气请求失败时展示错误与重试，不编造气压。
- 建议计算 < 5ms；天气请求超时 8s。
- 不把高德 Key 提交进 git。

## 6. 验收标准

1. 打开应用能看到上海天气，且包含气压、湿度。
2. 同一套天气输入，建议结果稳定可测（测试固定快照）。
3. 钓点 Tab 进入即定位并拉近附近视野；可搜索钓场；钓场列表按渔见得分排序并带名次与反馈条数；点条目打开本机详情而不是钓鱼之家网页；铭牌含头像、店名、五星；无照片用 Logo；拉远为小钉；点开可见客户反馈。开屏结束后与「+」页也会请求定位。
4. 粘贴小红书或抖音分享文案后可解析并钉到对应钓点。
5. 上报或导入一条渔获后标记立即出现，刷新仍在。
6. 未配置高德 Key 时应用仍能打开，并说明如何配置。
7. 高德 SDK 加载成功时状态为「高德已开启」。SDK 约 8 秒仍未完成则改用演示底图。点营地「打开高德地图」用可点链接跳转高德 App / 网页导航（手机不能依赖后台 `window.open`）。运行期始终请求 `/api/map-config` 合并 Key 与安全码。
8. 双击 `启动钓了嘛.bat` 能打开本机窗口；粘贴分享或公开链接后写入飞书多维表，并钉到地图。
10. `npm run scout:daily` 或桌面启动时，根据公开线索与手动链接生成当日 `fish_scout_data/reports/YYYY-MM-DD.md`。
12. 点营地钉打开详情：店名、五星渔见评分、反馈图文、导航；无反馈为空星并标「新」。
13. 上传或现场拍摄渔获照片可识别词表内鱼种（或明确「不确定」）；底栏「+」打开 AI 识鱼并可拍照。首页不放识鱼卡。「用这个鱼名上报」后地图附文含该鱼名。`normalizeFishName` 测试通过。
14. 首页展示可测的钓鱼指数与档位；底部「钓点」打开地图。
15. 识鱼从底栏「+」到达，同页可报渔获；钓点、渔圈走底栏；「我的」为个人中心，渔获记录从其中进入；天气详情点天气条打开。
16. 路亚拟饵随目标鱼变化：翘嘴/黑鱼/鳜/鲈/白条给出不同种类、克数或尺寸、颜色与操法；切换目标鱼立刻重算。
17. 今日天气栏展示晨间/黄昏窗口倒计时（距晨间窗口、距黄昏窗口）；同一时刻结果可单测。
18. 目标鱼列表随台钓/路亚筛选；鲫鱼不出现在路亚列表，鲈鱼不出现在台钓列表；兼钓鱼在两边都在。
21. 进入应用先显示 Logo 开屏；品牌名为渔见，标题字色与字族与 Logo 一致。
22. 渔见评分等于该钓点客户反馈星级的算术平均；界面用最多五星（含半星）展示，不显示数字分。本机新反馈会立刻改星。
23. 渔圈含商城、赛事、技巧、评测、社区群聊；商城不能支付；群聊消息可本机发送并保留；示例须标明。
24. 「我的」含头像昵称、渔获/关注/粉丝/想买四列、分组菜单；粉丝为示例名单；不强制登录、不接私信。手机网页上列表与「分享入库」表单底部留出底栏金色按钮与浏览器工具栏高度，避免被挡住。
25. 今日方案点「介绍」打开当前目标鱼说明与技巧；翘嘴含路亚拟饵与标点建议。

## 7. 成功标准（MVP）

本地 `npm run dev` 或 `启动钓了嘛.bat` 可演示上述主路径；`npm test` 覆盖建议引擎与入库提取。
