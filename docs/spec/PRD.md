# 钓了嘛 Product Spec（PRD）

> 状态：Approved for MVP  
> 日期：2026-08-17  
> 范围：上海地区钓鱼助手 Web 应用

## 1. 一句话

给上海钓友一张高德地图：看实时天气（含气压、湿度），据此推荐水层 / 鱼饵 / 钓法；把渔获情报钉在地图上；拍照让 AI 认出鱼种后再上报。

## 2. 目标用户

业余与半专业淡水 / 河口钓友，主要活动范围：上海及周边（滴水湖、淀山湖、崇明、滨江、公园湖等）。

## 3. 功能需求

### FR-1 实时天气

- 默认定位上海人民广场。手机上进入应用（开屏结束后）请求浏览器定位，用于天气、钓点附近与识鱼/报渔获坐标；打开底栏「+」或「钓点」会再定位一次。定位失败（未授权 / 非 HTTPS / 超时 / 不支持）仍用人民广场，并说明原因。允许在地图选点覆盖当前坐标：**选点后天气、钓鱼指数与今日方案改用该点**，报渔获坐标同一点。
- 展示：天气现象、气温、体感、相对湿度、海平面气压、3 小时气压趋势、风速风向、降水。点天气条打开的详情另展示**未来约 24 小时逐时**与**未来 7 天**（气温高低、天气现象、降水、风力）；每日可附一条钓鱼指数（由当日气温/气压/风/降水套同一套 `buildFishingIndex`，气压 3 小时变化按 0，不编造溶氧、水温）。
- 数据源：Open-Meteo（无需密钥，CORS 可用）。后续可替换为和风 / 高德天气，接口保持 `WeatherSnapshot`；预报为同接口的 hourly / daily。

### FR-2 作钓建议

根据 FR-1 的气象快照 + 当前小时 + 月份 + **用户选的目标鱼** + **台钓/路亚**，给出：

| 输出 | 说明 |
|------|------|
| 推荐水层 | 上层 / 中上层 / 中下层 / 底层 |
| 味型与饵形 | 台钓：味型+饵形；路亚：按对象鱼给出拟饵种类、克数/尺寸、颜色、操法 |
| 标点 | 水草区、进水口缓流、凸岸、草洞等，随对象鱼与气象变化 |
| 窗口 | 早晚优先 / 避开正午 / 按气压择时 |
| 理由 | 用气压趋势、气温、风力、对象鱼解释，避免空话 |

建议引擎必须是确定性规则（可单测），不在运行时调用大模型或再去网上搜。规则编译自公开垂钓经验（渔钓者味型与选点、龙国钓鱼频道饵料变更；路亚：渔夫者/钓鱼007 翘嘴亮片克数、渔钓者雷蛙操法、酷钓鱼铅头钩克数表、酷米网瓜子亮片），不是溶氧/水温实测，也不是线上实时大数据模型。

### FR-3 上海渔获情报地图

- 环境变量：`VITE_AMAP_KEY` / `AMAP_KEY`。无 Key、SDK 超时或失败时降级为国内可显示的高德栅格底图，并提示配置；不得一直停在「正在加载地图」。
- 每个高德标点**下方常显**附文，格式固定为：

  `某某某 多少时间之前 钓到了什么鱼`

  例：`沪上老张 3小时前 钓到了鲈鱼`

- 附文须带来源标签：小红书 / 抖音 / 微博 / 公开渔讯 / 钓友上报。
- **鱼情来源（必须覆盖）**：小红书、抖音，以及任何可合法获得的上海鱼情（公开网页、渔讯、用户粘贴的分享口令/文案）。
- 入库方式：① 粘贴小红书/抖音/微博/微信公众号分享文案或公开链接，解析谁、何时、何鱼、何地并钉到对应钓点；② 公开渔讯整理样本；③ 钓友本机上报。渔获库是飞书多维表格，由本机 `lark-cli` 读写，不再用 SQLite。
- **鱼情日报（FR-5）**：每日自动公开信息发现。已启用平台：小红书 `xiaohongshu.com`、抖音 `douyin.com`、微信公众号 `mp.weixin.qq.com`、B站 `bilibili.com`、贴吧 `tieba.baidu.com`、知乎 `zhihu.com`。只允许：① 用搜索引擎公开结果，按城市、平台、关键词生成查询；② 保存标题、摘要、链接；③ 对公开可访问网页尝试读正文；④ 登录墙平台仅保留标题、摘要、链接；⑤ AI 摘要、入库、生成 `fish_scout_data/reports/` 日报。不登录、不绕验证码、不模拟 App、不抓私密内容。公开发现使用项目 skill：`baidu-search`（千帆网页搜索，按平台 `sites` 过滤）、`multi-search-engine`（Bing 中国 / 百度网页 / 搜狗微信 / DuckDuckGo）、`defuddle`（仅非登录墙公开页抽正文）。每条命中必须属于**该条查询自己的** `site`（含别名），不能把别的平台结果混进当前查询。
- **不做**：登录用户账号去爬小红书/抖音/微信公众号全站、绕过验证码或接口签名。平台无开放检索 API 时，用分享入库 + 公开网页 + 公开搜索摘要，不用黑产爬虫。
- 用户可在地图上报自己的渔获，写入飞书多维表；浏览器 localStorage 只作离线缓存。
- 高德 SDK 真正加载成功后才显示「高德已开启」。
- **渔场目录（FR-6）**：地图与列表展示上海地区收费渔场 / 路亚营地 / 钓鱼营地。数据来自：① 大众点评公开商户页（店名、人均、状态）；② 钓鱼之家公开钓场目录（收费、区县、路名）；③ 路亚塘等公开页（仅收录有区县或路名的营地）。**钓点地图只显示营地钉，不常显长附文、不叠渔获气泡**，避免过密。每次从底栏进入「钓点」先定位，初始视野对准当前位置（约 14 级）；定位失败则仍用人民广场。拉远时营地收成小头像钉，靠近后再展开铭牌，避免全市大铭牌叠在一起。钓点页提供一份整合列表：默认按渔见均分从高到低排（同分看条数，无分排最后，名次用第 N），并可用搜索过滤（店名 / 区县 / 路名 / 类型）。列表另提供类型芯片（全部 / 路亚 / 池塘 / 海钓）、**营业中**、排序（渔见分 / 离我近）。离我近按当前位置到钓场的球面距离；每条排行显示**距离**与**反馈条数**（N 条反馈 / 暂无反馈）。点店名或条目进入本机钓场详情，不跳转钓鱼之家 / 大众点评 / 路亚塘网页；目录来源只作文案。详情展示距离、可复制地址、**附近 3 个钓场**（按该店坐标邻近，点开切到对应详情）。近期渔获按店名 / 去括号简称 / 路名匹配，不靠地图气泡。从排行进入详情后关闭，回到排行。地图上只保留一个「钓场」入口，不再分营地列表与排行榜。钓友可**收藏钓场**（按 `venueId`，本机 localStorage；登录后同步 `venue_favs`，再登录拉回并与本机合并）。详情有收藏按钮；「我的」有收藏列表，点开仍进本机详情。想买仍只对商城示例货。高德底图用官方浅色标准样式（`amap://styles/normal`），关闭默认兴趣点，画布未加载时用浅灰而不是深色。每颗钓场用**分类铭牌**：头像、店名、五星、类型、区县路名与收费。有客户反馈图则用该图作头像，**没有照片时用渔见 Logo**。白底圆角，下沿三角对准坐标。评分最多五星，可用半星，**界面不展示数字分**。内部仍按客户反馈星级均分（可单测）。无反馈为五颗空星并标「新」。不用圆圈也不用水滴。示例反馈用本机 `public/spot-photos/` 图（须真实存在、可显示），与虚拟星级，须标明示例。今日渔获示例封面在 `public/shares/`，同样须真实存在。钓友可在详情里写 1–5 星反馈（本机 localStorage，不写飞书）。不把点评星级直接当渔见分。不登录点评/钓鱼人 APP。不含免费野点与斤塘。坐标按公开区县与路名估算。暂停营业或已关门的仍列出（未勾选营业中时）。

### FR-7 AI 识别鱼种

详细规格见 [`docs/spec/FR-7-fish-id.md`](FR-7-fish-id.md)。

- 钓友上传或拍摄渔获照片，识别为上海对象鱼词表中的中文名，并给出置信度、最多 3 个候选、1–3 条外形依据。
- 置信度低或不是鱼时必须返回「不确定」，不得编造。
- 识别结果可一键填入报渔获并钉到高德，附文仍为 `某某某 多少时间之前 钓到了什么鱼`。
- 无豆包 API Key 时可手动点选词表，不算 AI 识别。
- 走火山方舟豆包识图接口，不自动登录豆包网页填表；照片不默认存公网。
- 手机优先：底栏「+」识鱼与同页报渔获都提供**拍照**（`capture=environment` 系统相机；安全上下文下可用实时取景）和相册。上报可将压缩图作为本机分享封面，可附最多 9 张图或一条短视频；不把 data URL / 视频文件写入飞书。

### FR-8 策略首页（深色金青绿）

- 默认打开**策略**首页，不是铺满地图。视觉按深底、金强调、青绿辅色。产品对外名 **渔见**。首页只保留：**品牌、天气条、今日最佳方案、今日渔获**。品牌行：`public/logo.svg` + 「渔见」（Logo 同款字族与渐变字色）+ 辅文 FISHING INSIGHT。进入应用先弹出开屏：金青绿光晕、水纹、Logo 淡入，点按或约 2.4 秒后进入策略页。点鱼名更换目标鱼；旁侧「介绍」打开该鱼说明。常用工具不占首页（钓点/渔圈走底栏，渔获记录从「我的」进入，点天气条打开天气详情）。AI 识鱼不放首页卡，走底栏中间金色「AI 识鱼」。
- 底部五个入口：**策略**、**钓点**（高德/降级地图）、中间金色按钮写 **AI 识鱼**（打开识鱼页，可拍照后上报；同页可手动报渔获；不用 + 号，按钮下方不另标「识鱼」）、**渔圈**（装备商城 / 赛事 / 技巧 / 评测 / 社区群聊）、**我的**（个人中心）。策略、钓点之后的下一主页面是渔圈。
- 天气条展示气温、出钓适宜度、风向风力、湿度与气压（一行辅文），以及窗口期倒计时。点天气条打开完整天气。
- **窗口期倒计时**：晨间窗口 05:00–08:00、黄昏窗口 17:00–20:00，与建议引擎 `prime` 小时一致。窗口内显示「晨间窗口剩余 / 黄昏窗口剩余」，窗外显示「距晨间窗口 / 距黄昏窗口」。每秒刷新。不依赖溶氧/水温。
- 今日最佳方案来自 FR-2：对象鱼、水层、**味形/拟饵**、**标点**。台钓/路亚切换与窗口倒计时不在方案格里重复。切换台钓/路亚或更换目标鱼会立刻重算，不另调模型。点鱼名换鱼；「介绍」打开本机鱼类习性与台钓/路亚技巧（`fishGuide`）；**「理由」打开建议依据**（气压趋势、气温、风力、对象鱼，即 `AdvicePanel`）。不联网、不编造溶氧水温。
- **目标鱼按钓法筛选**：台钓只列饵钓对象（鲫、鲤、草、青、鳊、鲮、黄颡、黄鱼、鲻鱼）；路亚只列掠食对象（鲈、翘嘴、黑鱼、鳜、鳡、红鳍鲌）；白条、罗非、鲶、塘鲺两边都可。切换钓法时，当前鱼若不匹配则改默认（台钓鲫鱼 / 路亚翘嘴）。识鱼上报仍用全词表。规则编译自渔钓者/酷钓鱼/饵料网公开对象鱼文，运行时不联网。
- AI 识鱼入口在底栏中间金色按钮（按钮上写 **AI 识鱼**，下方不重复「识鱼」）。进入后展示拍照/相册与识别结果（鱼名、置信度、外形依据）；无结果时引导去拍照。点按「拍照」优先打开后置相机（系统相机或本机取景），也可从相册选图。**已配置识鱼密钥时**界面不出现「豆包」或「打开豆包」；识别中弹出搞笑钓者把渔见 Logo 从水里钓起：表情轻微用力，旁白「嘿呀」，钓起即成功。首页不放识鱼卡。
- **钓友分享**：天气/方案留在上半屏不随分享被顶走。分享区在方案下方独立滑动（不显示滚动条）。区头为「今日渔获」加条数，右侧「全部 ›」，下沿细金线。**双列卡片**：封面限高约 108px，不必滑完一张图才看到下文。图上鱼种胶囊、示例黑底白字；图下标题一行、钓点名、点赞与评论数。**多图**最多 9 张，封面用第一张，角标显示张数；**短视频**一条、最长 15 秒且不超过 8 MB，角标为播放。登录后**照片与短视频**都上传到 Supabase Storage（公开桶 `yj-media`），渔获行只存 URL（`image_urls` / `video_url`）；今日渔获会合并云端渔获，别人点开详情即可看图或播放。未登录仍可本机预览，并提示去登录后别人才能看到。不把 data URL 写入云端行。点卡片打开短文详情：顶图可左右滑看图或播放视频，叠作者与时间，可关注/点赞/**评论**/**转发**（复制文案或发到主题群）。群聊/私聊里的转发显示为**渔获卡片**（封面、作者、钓点、鱼种），**点卡片打开原详情**，不得只复制一行字。找不到原文时卡片标明「原分享已不在」。「去钓点」为全宽青绿按钮。再切地图。「全部」进「我的」渔获记录。报渔获可从相册多选图片或选短视频。点赞与关注作者写入本机（登录后同步 `share_likes` / `share_follows`，**再登录时从云端拉回并与本机合并**）。评论写入本机（登录后同步 `share_comments`，拉回后与本机合并，示例评论仍标明示例）。**关注列表随操作增减**；粉丝含标明示例的种子钓友，外加关注了你昵称的云端用户。点作者打开**个人主页**（简介、渔获墙、关注）。不做约钓组队、导钓下单。
- **举报 / 拉黑**：按作者昵称拉黑（本机 `userSafety`，登录后同步 `user_blocks`，**再登录时拉回**）。拉黑后：今日渔获与评论不再出现此人；作者主页标明已拉黑并收起渔获墙；群聊隐藏其气泡；会话列表去掉与他的私信；不能再开私聊。举报须选原因（垃圾广告 / 辱骂骚扰 / 虚假渔获 / 其他），写入本机并可同步 `user_reports`。不能拉黑自己。入口：渔获详情、作者主页、群聊名片。「我的」有已拉黑名单，可解除。
- **钓鱼指数** 仍由气象规则算出 0–100 与档位（可单测）。不调用大模型，不编造日最高最低气温、溶氧、水温。
- 本机分享流可关注作者、点赞；不做一对一私信、约钓组队、导钓下单。桌面端以圆角手机列居中；地图在「钓点」Tab 常驻，切换时不卸载。首页留白优先于堆叠卡片。

### FR-10 我的（个人中心）

底栏最后一页，按常规 App 个人中心：

- 顶栏：头像（默认证见 Logo）、昵称、城市、一句简介。登录后点头像进入编辑：可改**名字**和**头像**（相册选图，压成小图；登录后上传 Storage 公开桶 `yj-media`，资料只存 HTTPS，群聊/主页别人才能看到；未登录仍本机 data URL）。未登录点头像去注册/登录。可选 **Supabase 账号**：用户只填**邮箱 + 密码**，提供 **注册 / 登录 / 退出**（不强制）。Project URL 与 publishable key 由部署环境提供（构建变量或运行时 `/api/public-config`），登录页不让用户填项目地址。账号出现在 Supabase Authentication → Users。未登录仍可用策略、钓点、识鱼。公网群聊发言必须登录。登录后资料、渔获、点赞关注、想买、收藏钓场、评测、拉黑、私聊开关会写入同一 Supabase 项目（本机仍作缓存）；**再登录时拉回并与本机合并**。未登录仍可看策略与钓点；上报渔获会先留本机，登录后同步。**secret key 只放服务器，不进前端。**
- 四列数据：渔获、关注、粉丝、想买。关注来自真实 `toggleFollow`。粉丝 = 示例种子（标明示例）+ 关注了你当前昵称的人。点关注/粉丝条目打开对方主页。**私聊**：粉丝名单每条都有「私聊」按钮。示例粉丝默认已允许私聊，点按钮即可进会话（未登录则去登录）。非示例粉丝须互关且双方允许，界面用 `canOpenFanChat` 禁用不可聊的按钮，不得为非示例粉丝自动打开「允许」。登录后消息进 Supabase，**Realtime 推送新私信**。本机私信写入同一会话列表，可发图。
- 分组列表：登录/注册、渔获记录、想买清单、**收藏钓场**、分享入库；定位与天气、鱼情日报；**已拉黑**；关于渔见。不在菜单再放「我的粉丝」（与四列粉丝重复）。已拉黑名单可解除，解除后渔获与私聊重新可见。
- 从首页「全部」进入时直接打开渔获记录。点渔获可导航到钓点地图。**自己上报的渔获**（本机用户记录）可编辑或删除；登录后更新或删除云端 `catch_reports` 对应行。不能改删示例帖或别人的云端渔获。
- 定位、重试天气、分享入库不再堆在首页式卡片里。

### FR-9 渔圈（第三主页面）

策略、钓点之后的主页面。底栏文案 **渔圈**。五个入口：

| 入口 | 行为 |
|------|------|
| 装备商城 | 本机示例商品目录（竿/轮/饵/线）。可加入「想买」。**不接支付、物流、第三方商城登录。** |
| 赛事 | 上海及周边示例赛事列表（时间、地点、项目）。标明示例，不接官方报名接口。 |
| 钓鱼技巧 | 台钓 / 路亚短文，正文写在本机 JSON，运行时不调模型、不联网。 |
| 装备评测 | 示例评测 + 本机 1–5 星写评（localStorage）。界面用五星，不展示数字分。 |
| 钓鱼社区 | 主题群列表（路亚夜聊 / 台钓鲫鱼 / 装备互助 / 赛事，沿用 `hub.json`，不另开大厅）。渔圈首页与「钓鱼社区」展示**会话列表**：四个主题群 + 有过私信的粉丝会话，显示最后一条预览与**未读数**；点进会话标已读。底栏「渔圈」有未读红点。点进群可看该群消息。**配好 Supabase 后为公网群聊**：所有人看到同一份消息；**不登录可看，登录后才能发言**。作者用当前昵称写入该条。消息存 Supabase 表 `chat_messages`，Realtime 推送新消息。未配云端时仍本机演示（localStorage + 示例种子），须标明。群聊按常见聊天 App：左右气泡、头像、时间分隔（今天/昨天/日期）、点普通气泡复制、**表情包**、**短语音**（最长 15 秒，正文 `[语音 N″]`；登录后上传 Storage，`media_url` 为公开地址，群内其他人可听；未登录或未配云端则本机预览）、**图片**（相册选图，压成 JPEG，正文 `[图片]`；登录后上传 Storage，`media_url` 为公开地址，群内其他人可看；未登录或未配云端则本机预览）、**短视频**（最长 15 秒，登录后上传 Storage，正文 `[视频]`，`media_url` 为公开地址，群内其他人可播）；**引用回复**（点「回复」引用该条，气泡上方显示被引作者与摘要，点摘要滚到原句；公网行用 `reply_to_*` 列，未建列时正文带 `#yjq:` 前缀）；会话列表与群内可**搜索**（标题/正文/作者）；再次进入有未读的会话时，在第一条未读前插入「以下为新消息」并滚到该处（本机 `lastRead`，不做群已读回执）；**转发渔获为可点卡片**；**点头像**打开名片（昵称、关注/取消关注、@TA、主页、**拉黑/举报**）。一对一私信仍从粉丝名单或会话列表进入，同样可发短视频、引用与搜索；配好云端后私聊与群聊一样走 Realtime。拉黑后不显示对方私信会话，群内也不显示其气泡。不做红包。 |

全部示例内容须能看出是演示。不登录钓鱼人 / 淘宝 / 微信。

## 5. 非功能

- 中文 UI；移动端优先（首页卡片 + 底部导航；地图在「钓点」）。手机需定位与相机权限；非 HTTPS 时系统相机选图仍可用，浏览器定位与实时取景不可用。
- 可部署到 **Zeabur**：控制台用 GitHub 仓库，或本机 `npx zeabur@latest deploy`。构建 `vite build`，启动 `npm start` 监听 `PORT`。云端 HTTPS，手机定位与实时取景可用。密钥只配 Zeabur 变量，不提交 `.env`。
- 天气请求失败时展示错误与重试，不编造气压。
- 建议计算 < 5ms；天气请求超时 8s。
- 不把高德 Key 提交进 git。

## 6. 验收标准

1. 打开应用能看到上海天气，且包含气压、湿度。
2. 同一套天气输入，建议结果稳定可测（测试固定快照）。
3. 钓点 Tab 进入即定位并拉近附近视野；可搜索钓场；钓场列表按渔见得分排序并带名次、距离与反馈条数；可用路亚/池塘/海钓与营业中筛选，可改按离我近；点条目打开本机详情而不是钓鱼之家网页；详情含距离、附近 3 场、匹配到的近期渔获；铭牌含头像、店名、五星；无照片用 Logo；拉远为小钉；点开可见客户反馈。开屏结束后与「+」页也会请求定位。地图仍只显示营地钉，不叠渔获气泡。
4. 粘贴小红书或抖音分享文案后可解析并钉到对应钓点。
5. 上报或导入一条渔获后标记立即出现，刷新仍在。
6. 未配置高德 Key 时应用仍能打开，并说明如何配置。
7. 高德 SDK 加载成功时状态为「高德已开启」。SDK 约 8 秒仍未完成则改用演示底图。点营地「打开高德地图」用可点链接跳转高德 App / 网页导航（手机不能依赖后台 `window.open`）。运行期始终请求 `/api/map-config` 合并 Key 与安全码。
8. 双击 `启动钓了嘛.bat` 能打开本机窗口；粘贴分享或公开链接后写入飞书多维表，并钉到地图。
10. `npm run scout:daily` 或桌面启动时，根据公开线索与手动链接生成当日 `fish_scout_data/reports/YYYY-MM-DD.md`。
12. 点营地钉打开详情：店名、五星渔见评分、反馈图文、导航；无反馈为空星并标「新」。
13. 上传或现场拍摄渔获照片可识别词表内鱼种（或明确「不确定」）；底栏「+」打开 AI 识鱼并可拍照。首页不放识鱼卡。「用这个鱼名上报」后地图附文含该鱼名。`normalizeFishName` 测试通过。
14. 首页展示可测的钓鱼指数与档位；底部「钓点」打开地图。
15. 识鱼从底栏「+」到达，同页可报渔获；钓点、渔圈走底栏；「我的」为个人中心，渔获记录从其中进入；天气详情点天气条打开。
16. 路亚拟饵随目标鱼变化：翘嘴/黑鱼/鳜/鲈/白条给出不同种类、克数或尺寸、颜色与操法；切换目标鱼立刻重算。
17. 今日天气栏展示晨间/黄昏窗口倒计时（距晨间窗口、距黄昏窗口）；同一时刻结果可单测。
18. 目标鱼列表随台钓/路亚筛选；鲫鱼不出现在路亚列表，鲈鱼不出现在台钓列表；兼钓鱼在两边都在。
21. 进入应用先显示 Logo 开屏；品牌名为渔见，标题字色与字族与 Logo 一致。
22. 渔见评分等于该钓点客户反馈星级的算术平均；界面用最多五星（含半星）展示，不显示数字分。本机新反馈会立刻改星。
23. 渔圈含商城、赛事、技巧、评测、社区群聊；商城不能支付；配好 Supabase 后群聊为公网主题群（不登录可看、登录可发，Realtime）；群聊有头像，点头像可看名片并关注；可发表情包、最长 15 秒语音与图片；可引用回复、搜索会话与群内消息；有未读再进会话时出现「以下为新消息」；渔圈首页有会话列表与未读；底栏渔圈显示未读红点；未配则本机演示并标明示例。私聊仅互关且双方开开关（界面用 `canOpenFanChat`，不为非示例粉丝自动打开允许），同样支持表情、语音与图片；配好云端后私信 Realtime。
24. 「我的」含头像昵称、渔获/关注/粉丝/想买四列、分组菜单；登录成功后回到该首页，四列与菜单仍可点；登录后点头像可改名字与头像；关注随操作变化；粉丝含示例种子，名单上常显「私聊」按钮（不可聊时禁用）。可选邮箱+密码注册/登录/退出。菜单不再重复「我的粉丝」。手机网页上列表与「分享入库」表单底部留出底栏金色按钮与浏览器工具栏高度，避免被挡住。
26. 渔获详情可评论、转发（复制文案或发到主题群）；登录后评论写入 `share_comments` 并再登录拉回；群聊/私聊里点转发卡片打开原渔获详情。点作者打开个人主页（渔获墙 + 关注）。示例评论须标明。
25. 今日方案点「介绍」打开当前目标鱼说明与技巧；点「理由」打开建议依据（气压/气温/风力，不编造溶氧水温）；翘嘴含路亚拟饵与标点建议。
27. 拉黑作者后，今日渔获、评论、群气泡与私信会话不再出现此人；作者主页可解除；「我的 → 已拉黑」可解除。举报须选原因并留下记录。不能拉黑自己。登录后拉黑名单从 `user_blocks` 拉回并与本机合并。
28. 今日渔获支持多图（最多 9 张）与短视频（≤15 秒）；封面用第一张图；多图/视频有角标；详情可滑图或播放。报渔获可多选相册。不把 data URL 写入飞书。登录后照片与视频上传 Storage，云端行只存 HTTPS。
29. 登录后把照片与短视频上传到 Storage；群聊/私聊与今日渔获只存 URL。未登录者可看别人的云端图/视频，自己发则需登录。前端不用 secret。
30. 群聊/私聊可引用回复（气泡上显示被引摘要，点摘要滚到原句）；会话列表与群内可搜索；再次进入有未读的会话时出现「以下为新消息」。不做群已读回执。
31. 天气详情展示未来约 24 小时与 7 天预报（Open-Meteo）；每日指数不编造溶氧水温。
32. 登录后头像上传 Storage，资料与聊天气泡用 HTTPS；未登录仍本机预览。
33. 登录后群聊/私聊语音上传 Storage，`media_url` 为 HTTPS。
34. 钓场详情可收藏；「我的 → 收藏钓场」列出已藏营地并可打开详情。登录后 `venue_favs` 拉回合并。
35. 「我的 → 渔获记录」对自己上报的渔获可编辑或删除；登录后同步云端行。不能改删示例或别人的渔获。地图仍只显示营地钉。
