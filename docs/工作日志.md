# 渔见项目工作日志（开工至今）

- **产品对外名**：渔见  
- **仓库名**：钓了嘛 / GitHub `w555w555/diaolema`  
- **起止**：2026-08-17 ～ 2026-08-18  
- **形态**：Vite + React 19 + TypeScript 单页应用；本机 Node 入库；可部署 Zeabur  
- **一句话目标**：给上海钓友看实时天气（含气压、湿度），据此推荐水层 / 鱼饵 / 钓法；渔获钉在高德上；拍照让 AI 认出鱼种后再上报。

---

## 一、按日记录

### 2026-08-17（开工日）

**规格与工程**

- 开启 Spec + SDD：`docs/spec/PRD.md`、`docs/spec/SDD.md`、Cursor 规则。
- 脚手架：Vite / React 19 / TypeScript / Vitest。
- 建议引擎纯函数可单测（不调大模型、不编造溶氧水温）。
- `npm test`、`npm run build` 通过；`npm run dev` 可跑。

**天气与作钓建议（FR-1 / FR-2）**

- Open-Meteo 拉气温、体感、湿度、海平面气压、3 小时气压趋势、风、降水、天气现象。
- 默认坐标上海人民广场。
- 按气象 + 小时 + 月份 + 目标鱼 + 台钓/路亚给出：水层、味型/饵形或拟饵、标点、窗口、理由。
- 钓鱼指数 0–100 与档位（很高 / 较高 / 一般 / 偏低 / 不宜），可单测。
- 台钓：味型、饵形随气温气压对象鱼变化。
- 路亚：按对象鱼给出拟饵种类、克数/尺寸、颜色、操法（编译自渔夫者、钓鱼007、渔钓者、酷钓鱼、酷米网等公开文）。
- 目标鱼按钓法筛选：台钓鲫鲤草青鳊鲮黄颡黄鱼鲻；路亚鲈翘黑鳜鳡红鳍鲌；白条罗非鲶塘鲺兼钓。
- 天气条晨昏窗口倒计时：晨 05:00–08:00、昏 17:00–20:00，文案「距晨间窗口 / 距黄昏窗口」等。

**地图与渔获（FR-3）**

- 高德 JS API 优先；无 Key 或失败则 Leaflet + 国内可显示的高德栅格底图。
- 高德 SDK 真正加载成功才显示「高德已开启」。
- 路线规划与高德导航跳转。
- 渔获附文格式：`某某某 多少时间之前 钓到了什么鱼`，带来源标签。
- 分享口令 / 公开链接入库（小红书、抖音、微博、公众号等）；不登录、不爬全站、不绕验证码。
- 本机 `启动钓了嘛.bat` 打开独立窗口；入库由 SQLite 改为飞书多维表（`lark-cli`）。
- 每日鱼情日报：公开搜索摘要 + 手动链接 → `fish_scout_data/reports/`。公开发现只用项目内三个 skill：`baidu-search`、`multi-search-engine`、`defuddle`。
- 上海收费渔场 / 路亚营地目录：大众点评公开商户、钓鱼之家、路亚塘公开页；地图钉营地，排行按渔见评分。

**AI 识鱼（FR-7）**

- 规格与实现：词表归一化、本机 `/api/fish-id`、火山方舟豆包识图。
- 低置信度或不像鱼返回「不确定」，不编造。
- 识别后可「用这个鱼名上报」钉到地图。无 Key 可手选词表。

**首页 / 渔圈 / 我的（FR-8 / FR-9 / FR-10）**

- 产品名改为渔见；Logo 开屏（金青绿光晕、水纹、轻触或约 2.4 秒进入）。
- 桌面端 430px 圆角手机壳，深底金青绿。
- 底栏五入口：策略、钓点、中间发布/识鱼、渔圈、我的。
- 策略首页：品牌、天气条、今日方案、识鱼入口、今日渔获分享。
- 今日方案点鱼名换鱼，「介绍」打开本机鱼类习性与技巧。
- 钓友分享：双列卡片、示例短文与封面、本机点赞/关注（localStorage），无私信、无粉丝体系写飞书。
- 渔圈：装备商城（不能支付）、赛事、技巧、评测、本机群聊。
- 我的：头像昵称、渔获/关注/粉丝/想买、分组菜单；粉丝为示例名单。

### 2026-08-18

**钓点**

- 地图去掉长附文和渔获气泡，只留营地钉；拉远小钉、靠近铭牌。
- 无反馈标「新」；五星展示，界面不显示数字分。
- 点钉 / 排行条目进本机钓场详情（反馈图文、写评、导航），不跳转钓鱼之家网页。
- 排行显示反馈条数；搜索店名 / 区县 / 路名 / 类型。

**渔圈与方案**

- 渔圈改为入口条 + 赛事 / 装备 / 群聊 / 技巧预览，避免空磁贴。
- 今日方案「介绍」可看当前目标鱼习性与台钓/路亚技巧。
- 窗口倒计时文案统一为距晨间窗口 / 距黄昏窗口。

**手机能力**

- 开屏结束后、钓点、识鱼页请求浏览器定位；失败说明原因并回落人民广场。
- 识鱼与报渔获：系统相机 `capture=environment` 或 HTTPS 下实时取景；取景有「返回」「拍摄」。
- 识鱼上报可带压缩封面，不把 data URL 写入飞书。

**部署**

- Zeabur：`zbpack.json` + `npm start` 听 `PORT`。
- 控制台用 GitHub 仓库，或本机 `部署到Zeabur.bat` / `npx zeabur@latest deploy`。
- 源码推送到 https://github.com/w555w555/diaolema （`main`）。
- 高德：本机 `.env` 的 `VITE_AMAP_KEY` / `VITE_AMAP_SECURITY_CODE`；云端配同名或 `AMAP_KEY` / `AMAP_SECURITY_CODE`；白名单含 `localhost`、`127.0.0.1`、`*.zeabur.app`。根目录留空或 `/`，不要填命令。

**首页与识鱼入口调整**

- 今日方案不被压扁；今日渔获独立滑动；卡片压矮，露出钓点名与点赞。
- 首页去掉 AI 识鱼卡。
- 底栏中间金色按钮改为「AI 识鱼」（AI 大字、识鱼小字），无加号、无按钮下方重复「识鱼」。
- 点该按钮进入识鱼页（拍照 / 相册 / 上报），同页可手动报渔获。

**验收**

- 本机打开策略、钓点、AI 识鱼、渔圈、我的，以及钓场详情、商城、群聊、渔获记录、鱼情日报、鱼类介绍、渔获短文，均可进入，无白屏。
